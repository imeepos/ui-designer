## 一、方法论：Prompt-as-Code

该仓库的核心思想：**把散文式 prompt 压缩成结构化协议**，让批量生成、模板系统、自动化工作流可复用。

1. **三种模板形态**（由低到高可控性）：
   - 自然语言填空模板：`为[产品类型]生成一张[平台]界面图…`
   - JSON 进阶模板：字段即约束，官方标注「推荐给 Agent 调用」
   - 参数化模板：`{argument name="brand name" default="..."}` 参数槽，一次定义、批量换参复用
2. **提示词六块结构**（官方 Skill 给出的组装顺序）：
   `主体与任务 → 构图与布局 → 视觉风格与材质 → 文字与标签要求 → 比例与输出格式 → 约束与负面清单`
3. **匹配顺序**：模板类别 → 风格标签 → 场景标签 → 最近似案例；多个候选时给 2-3 个方向让用户选。
4. **先抄结构、再抄风格词**：从案例学的是版式骨架，不是形容词堆砌。
5. **用途前置**：一上来写「任务目标和用途」建立全局上下文，再写视觉细节。

## 二、UI / 界面设计（tpl-ui）

### 2.1 常规 UI 模板骨架（五要素 + 输出约束）

```text
为[产品类型]生成一张[平台 iOS/Android/Web]界面图。
核心功能：[A]、[B]、[C]。
视觉风格：[极简/科技/拟物]，主色[颜色]，强调色[颜色]。
布局：[顶部导航/双栏/卡片流]，信息层级清晰，留白充足。
输出：高保真UI截图，文字清晰可读，比例[9:16/16:9]。
```

JSON 进阶模板字段：`type / platform / product / layout / style{theme, primary_color, typography} / content{header, cards[]} / constraints`。

### 2.2 社媒截图模板要点

- 分区描述：账号信息（头像/用户名/认证标识）→ 正文（写死中文文案）→ 互动数据（点赞/评论/转发具体数值）→ 顶部（状态栏/导航/搜索）→ 底部（操作栏/Tab/输入框）→ 附加（浮窗/弹幕/特效卡片）。
- **平台特征必须点名**：X 有蓝勾认证与转发/引用之分；抖音有音乐碟片和点赞动画；小红书是双列瀑布流。不指定平台模型会混搭（防坑指南原话）。
- 极简一句话版也有效（例 260/288/289）：`生成抖音直播间界面，内容是…`——平台特征词本身携带大量 UI 结构先验。

### 2.3 直播界面模板要点

- **先定直播类型**：带货直播（右上商品列表+倒计时+券卡）与才艺直播（重弹幕互动）布局差异大。
- UI 叠加层分区清单：顶部（主播头像+关注按钮+在线人数+榜单）/ 左下弹幕列表（条数+内容示例）/ 右下商品卡片（讲解中状态、价格、抢购按钮）/ 底部输入框+功能图标。
- 弹幕要**写具体内容**且合理（例 21/149/152/156/158/159 全部显式列出每条评论）；约束「界面元素不遮挡主播面部」。

### 2.4 UI 防坑指南（原文提炼）

- **不要模糊指令**：明确「平台 + 比例 + 布局」，否则乱排版。
- **强制文字锁定**：`文字绝对可读，必须显示指定的中文，禁止乱码和占位文本`。
- **特殊屏幕比例前置**：车机 21:9 等固定比例必须写在最前面（例 177），否则默认出手机 9:16。
- 文案克制：模型不是排版工人，图表/界面场景优先短句。

## 三、LOGO / 品牌设计（tpl-brand）

### 3.1 模板体系（从单点到系统）

1. **常规模板**：品牌关键词（3 个）先行 → Logo 方向（几何/字标/图形）→ 辅助图形 → 主辅色 → 应用示意。
2. **完整品牌身份包**：战略基础（原型/核心承诺/定位/差异化/唯一关键词）→ Logo 概念 3-5 个完全不同的方向 → 配色系统（主/辅/强调/中性 + HEX + 心理学 + 禁用搭配）→ 字体系统（层级/字距/免费替代）→ 应用触点（名片/App 图标/网站/广告牌/包装）→ **3 条永远不要打破的品牌规则**。
3. **品牌触点系统视觉板**：明确「不是单张海报，而是一套完整品牌应用展示」；触点清单 = hero shot + 包装物料 + 菜单卡/价目表 + 生活方式场景；构图要求「像顶级设计机构提案页，主视觉最突出、辅助物料层级清楚」。
4. **品牌包络产品广告**（四阶段，换产品保风格）：`PHASE 1 ANCHOR 品牌世界 → 2 INJECT 产品注入 → 3 FORMAT 输出格式 → 4 SIGNATURE 品牌签名元素`。
5. **品牌人格漫画信息图**：把品牌变成角色（服装/姿态/语气全部来自 Logo），周围 6-8 个分镜 + Voice tone/Energy/Social behavior/DO·DON'T 模块。

### 3.2 Logo 防坑指南（原文提炼）

- **做减法**：先定品牌关键词再出图。「喷火龙缠绕长城柱子带闪电」不叫 Logo，叫插画。
- **强制纯白背景**（Pure White Background），方便后期抠图。
- **先战略后图形**：缺受众/竞品/情绪目标，Logo 只是漂亮图形，解释不了为什么适合品牌。
- **Logo 必须看应用场景**：同图展示名片、App 图标、网站、广告牌，立刻暴露缩小不可读、横竖比例不适配问题。
- **品牌手册要写禁用规则**：只给色板字体不写「不要怎么用」，延展必跑偏。
- 品牌只做点缀：调性体现在细线、强调色、字体气质和光影，不要 logo/大色块铺满画面。

## 四、组件设计

- **组件=位置+类型+内容**的最小三元组描述（例 161 HUD：`{position, type, text}`）。
- **卡片规范参考**（签名海报模板，可迁移到组件陈列）：统一尺寸、统一间距、整体对齐、圆角 8-16px、极细描边或无边框、极轻阴影、「高级杂志排版，避免强 UI 感」。
- **组件一致性批量生成**（例 186 百件道具图鉴）：10×10 网格、行主题分组、每格独立方块+下方短标签、`limited palette per sprite`、「小尺寸下易于辨认」、白底整洁网格。
- **控件/按钮出现在设计系统一句话模板中**（例 243）：网页/移动端/卡片/控件/按钮成套生成——同 batch 天然同风格。
- 动作/状态分解类（16 宫格动作表）：面板数量、编号、每格结构（顶部标题/中央姿态/底部说明/叠加箭头）必须显式锁定，否则挤成杂乱说明图。

## 五、页面设计

- **Landing Page 通用骨架**（例 131/134-137 综合）：`header(logo+导航逐项+CTA) → hero(标题/副标题/双按钮/三特性图标) → 信任区(数据卡片/统计条) → 内容区(section 数组) → 社证(logo 墙+见证卡) → CTA(输入框+发光按钮)`。
- **页面级防坑**：栏数（columns）与留白（margins）比风格词更重要（文档与出版物节原文）；正文用「模拟文本块（Simulated text blocks）」只写死大标题。
- **个人网页**（例 336）、**角色介绍页**（例 263，galgame 风格介绍页带表情差分/CG/参数表）：页面可以是「信息架构+人设」的混合体。
- **数据可视化区块**：图表类型显式指定（折线/分段条形），数值写死（如 TikTok 52% / Instagram 24%…），杜绝模型编数。

## 六、总览（Board / 设计系统总板）

「总览类」出图的共同心法——**一张图讲清一套系统**：

1. **分区标题+编号是骨架**：例 132 的 `01 品牌DNA / 02 概念构思 / … / 18 最终主视觉`、例 133 的十大分区。分区名用「中英双语编号标题」最稳。
2. **每个分区显式声明元素与计数**（`elements: [...], count: N`），整体给网格规格（3 列×6 行 / 10×10 / 2×3）。
3. **统一性约束**：所有面板共享一套配色和字体逻辑；「像顶级设计机构提案页，整齐但不死板」。
4. **全册预览验证**：企业画册类补一张全册系统预览图，验证封面/内页/案例页/联系页统一性。
5. **信息克制**：每阶段只保留短标题和关键标签；留白 ≥40%；模块 3-5 个为佳。
6. **研发提案板结构**（概念产品研发拆解板，可迁移到「总板」）：中心 hero render + 左侧形态分析 + 中部迭代过程 3-5 步 + 下方使用场景验证 + 右侧结构分层拆解 + 底部材质与规格表。

## 七、跨类别通用心得（防坑清单汇总）

| 心得 | 说明 |
|---|---|
| 文字硬编码 | 主副标题写死，否则模型疯狂加戏编字；中文要求「拼写完全正确、禁止乱码」 |
| 负面约束具体化 | `no gibberish text / no modern elements / no watermark / 不要通用放大镜图标`——禁什么写什么，别只写「要真实」 |
| 比例前置锁定 | 比例写在 prompt 最前面；特殊比例（21:9）必须显式 |
| 数量显式化 | 模块数、卡片数、导航项数、面板数全部给 count |
| 一致性前置 | 「同一角色/同一服装/同比例」写在列表之前（越长序列越容易漂移） |
| 同体锁定 | 试色/换装类明确「同一张脸，仅 X 变化」 |
| 材质+光影 | 材质关键词（磨砂/铬/玻璃）与灯光（轮廓光/柔光棚拍）堆叠，缺光影即廉价 |
| 参数说话 | `f/1.4` 优于「浅景深」，`50mm` 优于「半身照」 |
| 主体放大 | 科普/海报类主体占画面 50%-70%，成为唯一视觉中心 |
| single 输出 | `Single poster only, no moodboard`——防止生成多方案展示板、过程稿 |
| 品牌点缀律 | 品牌色只用于细线/小标题/icon（20-30%），不大面积铺色 |
| 加瑕疵增真 | skin pores / film grain / 自然杂乱——太完美反而假 |
| A/B 输出 | 通用场景直接要求「一版主方案 + 一版备选方案」 |
| 大师名慎用 | 提特征（「梵高的旋转星空笔触」）而非直接写名字，避免构图照搬 |
| 强制可读性 | 小尺寸场景（图标/图鉴/缩略图）明确「缩小后可读/instantly readable at small sizes」 |
