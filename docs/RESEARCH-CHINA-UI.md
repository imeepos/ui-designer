# 中国风 UI 设计学习笔记（重设计前置研究）

> 目的：为「舵 Rudder」整体界面的中国风重设计提供设计语言依据。
> 产出应用于：`design-china/` 重设计项目（rudder CLI 自举）→ `docs/THEME.md` v3 主题提案 → `src/index.css` 落地。
> 主要参考：[中国传统色调色板指南 · Chinese Color Atlas](https://chinesecoloratlas.com/zh-Hans/guides/chinese-color-palette)、[宋代美学配色](https://chinesecoloratlas.com/zh-Hans/palettes/song-dynasty)、[水墨网页配色](https://chinesecoloratlas.com/zh-Hans/palettes/ink-wash-web)。

## 1. 核心认知：中国风 ≠ 红金堆砌

好的中国风 UI 不是装饰元素的叠加，而是把传统色与构图法则**转译成设计系统的角色**：

- 每个颜色必须有明确 UI 角色（primary / accent / background / foreground / border），并过 WCAG AA 对比度。
- 推荐比例 **60 / 25 / 10 / 5**：主色与浅色承担大面积界面，点缀色只给焦点与关键动作，深色负责文字与层次。
- 常见公式：**宋式**＝天青＋月白＋缃色＋墨灰（素雅淡泊）；**水墨**＝墨色打底＋月白为字＋朱砂为 CTA；**敦煌**＝矿物蓝绿＋暖赭＋沙色中性。

## 2. 构图与气质法则

| 法则 | 含义 | 在工具 UI 的落法 |
|---|---|---|
| **留白**（计白当黑） | 负空间是构图的一部分，宋代「素雅淡泊，留白有度」 | 卡片内边距加大、区块间 24px 起、画廊网格不过密；空态大面积留白 |
| **白描线稿** | 单色细线勾勒，不施丹青 | 图标 1.5px 单色线稿；空态插画用水墨帆舟/舵轮/罗盘线稿 |
| **边框优先** | 传统界格（版框）以细线分区 | `1px solid var(--border)` 优先于阴影，与现有 THEME 纪律天然一致 |
| **印章点睛** | 朱砂印是全卷唯一浓色 | 品牌 logo 用「舵」字白文方印；朱砂只用于 destructive 与 5% 级点缀 |
| **纹样克制** | 回纹/云纹只作极细辅助 | 分隔线或空态背景可用极淡回纹，禁大龙大凤大渐变 |
| **方中带圆** | 界格方正、转角微圆 | 保持小圆角体系：按钮 4 / 输入 6 / 卡片 8 / 弹窗 12 |

## 3. 选色方案：「苍青墨航」色系

从宋代美学与水墨网页公式出发，为工具 UI 调深/调稳（保对比度）：

| 角色 | 传统色名 | Hex | 说明 |
|---|---|---|---|
| `--primary` | **苍青**（天水碧加深） | `#2C6E78` | 主按钮/激活态/选中框；白字对比 ≈ 5.4:1（AA ✓） |
| `--primary` 弱化 | 天水碧 | `#5AA4AE` | hover、次级强调、缩略图 |
| `--accent` | **缃色**（浅金加深） | `#D9A514` | 焦点环、步条当前步；黄铜色的中国色近亲，承接原舵柄意象 |
| `--destructive`/印章 | **朱砂** | `#C3402B` | 删除/错误 + 品牌「舵」字印；浅底文字对比 ≈ 5.0:1 |
| `--foreground` | **墨玄** | `#3A4247` | 正文，纸底对比 ≈ 9:1 |
| `--muted-foreground` | **墨灰** | `#5C6E80`（#758A99 加深） | 说明文字，纸底 ≈ 4.8:1（#758A99 原值仅 4.2:1，不达标故加深） |
| `--border` | **淡墨** | `#E3E4DC` | 发丝分隔线 |
| `--background` | **宣纸** | `#F7F5EE` | 微暖纸底（比原 #FAFAF8 更纸感） |
| `--card` | **纸白** | `#FFFFFF` | 卡片面 |

dark 模式：**墨绢** `#161C1E` 底、雾白字、苍青提亮为 `#6FB4BD`、缃色与朱砂按深底可读性微调。

## 4. 字体

- **标题**：思源宋体 / Noto Serif SC——书卷气的关键；页题、区块题用宋体。
- **正文**：`Inter + PingFang SC / Noto Sans SC`——保持工具高密度可读性。
- **数字/参数**：JetBrains Mono（seed、尺寸、hex 标签），延续原规范。

## 5. 与「舵」品牌基因的融合：墨航（Ink-Voyage）

舵的原始气质＝航海掌舵（沉稳、专业、克制）。中国风转译不是换掉航海母题，而是**换画法**：

> **墨航** —— 同一片海，从「深海军蓝的军舰」驶入「宋代水墨的绢本手卷」。

- 母题保留：舵轮、罗盘、帆舟、锚——全部改用**白描线稿**表达。
- 意象升级：深海军蓝 → 苍青（青瓷/天水碧系）；黄铜 → 缃色；纸白 → 宣纸。
- 点睛：朱砂「舵」字方印作为 logo 与空态落款，全界面唯一暖红。

## 6. 约束清单（防生成跑偏）

1. 禁：红金婚庆配色、龙凤祥云大纹样、重渐变、重阴影、拟物。
2. 禁：把低对比传统色（月白/缃色原值）直接当正文色。
3. 小字号 CJK 标签 ≥11px，禁全大写+加粗+宽字距三件套同用（沿用 UI-REVIEW §7 结论）。
4. 图片中的中文标签必须逐字指定（Labels 逐字约束），防止花字/自造词。
5. 生成图片探索一律 `quality: low`，终版才 `high`（预算纪律）。
