# 舵 Rudder · PRD v0.1

> AI 成套 UI 设计工作室。用 gpt-image-2 把「设计系统总板 → 功能页面 → 组件」一次性生成风格一致的成套界面设计图，并通过 CLI + Skill 供 AI 编码代理驱动。

## 0. 产品边界（哲学，最高优先级）
**舵是工具，不是代理。**
- 舵**永不内置大模型调用**：LLM 智能由外部编码代理（Codex/Claude Code 等）自带。
- **CLI = 代理的操作面**：命令集按"代理可消费"设计（--json/--dry-run/结构化错误/模板骨架+填槽指南/`--prompt-file` 接受代理生成的最终提示词）。
- **GUI = 人类的查看器**：浏览项目、查看图片与血缘、手动触发；不追求替代代理的智能。
- 模板系统 = 骨架 + 逐槽填槽指南（fillGuide），供代理读取后用自己的 LLM 填槽，再经 `--prompt-file` 回灌。

## 1. 一句话定位
为独立开发者与 AI 编码代理设计的**极简 AI UI 设计工具**：四步走完「新建项目 → 设计系统总板 → 功能页面 → 组件设计」，产出风格一致的成套 UI 设计图 + 可导出的设计资产包。

## 2. 目标用户
1. 独立开发者 / 小团队：需要快速得到成套、风格统一的 UI 设计图。
2. AI 编码代理（Codex / Claude Code 等）：通过 CLI + Skill 自主完成设计产出。

## 3. 核心流程（v0.1 全部实现）
### 3.1 新建项目
- 输入：项目名 + 画布尺寸预设（Web 1536x1024 / Mobile 1024x1536 / Desktop 2560x1440 / 自定义，遵守 gpt-image-2 约束：边长 16 倍数、宽高比 ≤3:1、总像素 65万~829万）。
- 产出：项目工作区（本地目录 + 元数据 JSON）。

### 3.2 设计系统总板（风格锚点）
- 输入：品牌关键词、配色方向、字体气质、圆角/密度、参考描述（可选）。
- 行为：一次调用生成 n 张候选总板（色板+字阶+按钮/卡片/输入框组件+图标风格，画在一张图上），`quality=high, thinking=medium`。
- 用户选定 1 张 → 设为**锚点图**，后续所有生成均以它为 Image 1 参考。

### 3.3 功能页面设计
- 输入：页面 slug + 布局简报（信息架构描述，可给布局参考图）。
- 行为：`images/edits`，锚点图为 Image 1；提示词含不变量清单（严格沿用配色/字体/圆角/组件样式）。
- 支持重生成（保留历史版本）、删除、查看大图。

### 3.4 组件设计
- 输入：组件类型（按钮/卡片/表单/导航/图标组等）+ 简报。
- 行为：锚点图(+可选页面图)为参考，生成组件细节图。

### 3.5 导出
- 一键导出资产包：全部图片（按 board/pages/components 分目录）+ `manifest.json`（项目元数据、每张图的 prompt/seed/尺寸）+ `PROMPTS.md`（提示词日志）。
- DESIGN.md 的 token 提取由**使用 Skill 的 AI 代理**完成（工具不内置文本模型依赖）。

## 4. 非功能需求
- 桌面端（macOS 优先）+ CLI 双入口，共享同一核心库与同一项目存储格式。
- 极简 UI：三栏（项目列表 / 画廊 / 详情+操作面板），无多余装饰。
- 多语言：zh-CN、en，i18n 资源化，新增语言只加 JSON。
- API 凭证从环境变量 `OPENAI_API_KEY` / `OPENAI_BASE_URL` 读取，永不落盘明文。
- 所有生图调用支持 `--dry-run`（只出请求计划不花钱）。

## 5. 明确不做（v0.1）
- 不做画布编辑器、不做图层、不做矢量编辑（借鉴期结论：图定方向，代码抠细节）。
- 不内置文本 LLM；不做团队协作、云同步；不自建服务端——账号与按次计费由外部 cms 服务（`veren.top/api`）承载，客户端只做对接。

## 6. 验收口径（v0.1 整体）
1. 桌面端四步流程可走通（真实 API 产出图片）。
2. CLI 全命令可用，`rudder e2e` 一条命令从建项目到导出资产包。
3. `pnpm build`、`cargo check`、`cargo clippy` 零 error；核心逻辑有单测。
4. 可打出 macOS 安装包（.dmg/.app）。
5. 中英文案完整覆盖，无硬编码文案。
